--- Сервисы Хостинга ---

- origin - имя удаленного репозитор по-умолчанию
git push - lokal -> repoz . Загрузка изминений из локал ветки в ветку удален репозитор
git pull - repoz -> lokal . Загрузка изминений из ветки удален репозитор в локал ветку

- Подключение удален репозитория
git remote add origin <url>  // где origin имя удален репозитория  

- Клонирование удаленного репозитор в локальный
git clone <url>

- просмотр веток в удален. репозитор
git branch -a

- Загрузка изминений из локал. ветки в удаленную с созданием связи между ними
1) делается при первом связывании
git push -u origin <branch> // origin - название удален сервера (на какой грузим), <branch> - имя удаленной ветки в которую грузим
2) в дальнейшем просто git push

-  Скачиваем ветку
git pull
